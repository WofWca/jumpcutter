Jump Cutter Extension Test Page

This page tests the Jump Cutter extension with per-tab control. The extension should:

  • Inject into this page automatically
  • Show a draggable overlay button (🚀) in the top-right corner
  • Allow per-tab enabling/disabling via the overlay button
  • When enabled, detect silences in the video and skip them
